# 🐾 PawCasino — The Dog House Slot Machine

PawCasino is a fun, lightweight, and fully offline slot machine game featuring the "The Dog House" theme. Play with **PawCoins** — a virtual currency with no real-world value, designed for pure entertainment!

### 💭 More about this game

- 🎰 **The Dog House Slot** — 5 reels, 3 rows of canine-themed action
- 🦴 **Bonus Multipliers** — land the right combinations to trigger massive bonuses up to **100x**
- 💬 **Live Chat (simulated)** — interact with a simulated community of dog lovers
- 🏆 **Leaderboard** — compete against bot players for the top spot
- 🛒 **Coin Shop** — "purchase" virtual PawCoins to keep the fun going
- 💾 **Persistence** — balance and stats are automatically saved to your browser's local storage
- 📱 **Responsive Design** — play on desktop, tablet, or mobile phone
- 🔒 **Privacy Focused** — no data leaves your machine, 100% offline-capable
